### OPEN QUESTION 1 — RESOLVED by orchestrator spike (VERIFY-001 can be dropped)
Ran a real vitest/jsdom spike against `src/components/ui/dialog.tsx`. Result: **`DialogClose`
works fine.** All cases passed:
- CASE A — the built-in X button (`DialogPrimitive.Close render={<Button variant="ghost"/>}`,
  dialog.tsx:63-76) DOES dispatch and closes the dialog.
- CASE B — bare `<DialogClose>` (no render prop) closes the dialog.
- CASE C — explicit `onClick` fallback closes the dialog.
→ The mobile drawer can use the standard `DialogContent` close button. The planned
`showCloseButton={false}` + explicit-onClick fallback is **unnecessary**; don't build it.
→ Incidental observation: `DialogTrigger render={<Button/>}` fired `onOpenChange` once in jsdom,
  i.e. it did NOT visibly swallow the click. **Do not act on this.** jsdom is not a browser and
  this is out of scope. Keep following AGENTS.md's documented direct-`onClick` rule.
The temporary `src/app/verify-dialog/` scratch route and the spike test have both been deleted.

### THE core design finding — inline oklch literals, not tokens
`globals.css` defines a full token set (`--background --card --border --primary --muted-foreground
--sidebar*`, radius, chart colors) — but the components **bypass it almost entirely** and hardcode
raw `oklch(...)` values in inline `style={{}}` props. `Sidebar.tsx` and `Header.tsx` are ~90%
inline-styled this way; `InventoryClient.tsx` and `MenuClient.tsx` build badge colors from inline
`${color}20` / `${color}40` string concatenation.

This is the structural reason the UI reads as "assembled" rather than "designed":
- there is no single source of truth, so color/spacing drift is guaranteed;
- inline styles **cannot express breakpoints**, which directly blocks the responsive nav work;
- inline styles cannot express hover/focus states, which blocks the a11y requirements.

→ The overhaul's foundational task must be: establish a real type scale + spacing rhythm +
semantic token layer in `globals.css`, then restyle components **against tokens**, deleting the
inline oklch literals as it goes. Everything else in the overhaul depends on this landing first.
